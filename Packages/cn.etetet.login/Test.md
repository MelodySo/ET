# MongoDB 账号登录验证清单

## 目标

保留 Router / Realm / Gate 链路，在发放 Gate Key 前验证持久化账号，在线 Player 关联稳定账号 ID。
用户选择本地 Demo 的首次登录自动注册：合法账号不存在时创建，已存在时必须校验密码，不允许覆盖。

## 自动化验收

1. 使用真实 MongoDB，测试数据库名称使用独立 LoginAccountTest 前缀和随机标识，不连接游戏业务数据库。
2. 首次登录创建账号，账号 ID 大于零；再次登录校验密码，错误密码失败且不改变原账号。
3. 账号字段标准化，唯一索引阻止重复创建；并发创建同一账号只能有一份记录。
4. 数据库记录不含明文密码，相同密码不同账号使用独立随机盐。
5. 非法账号、空密码、过短或超长密码不能创建或认证成功。
6. 重新创建数据库访问组件后，同一账号仍可登录且 ID 不变。
7. Gate 只接受有效凭据，在线 Player 使用认证得到的稳定 ID，登录失败不进入大厅。
8. 真实客户端 Realm -> Gate 登录成功；错误密码不获取 Gate Key；现有进入地图机器人回归。
9. 数据库不可用时失败关闭，禁止退回内存免密登录。

## 执行

先 dotnet build ET.sln，再使用 ET.App 的 Test 命令按 Login_Account 筛选。
每轮保留旧日志到独立备份目录后运行，检查控制台结果和 Logs/All.log。
测试在 finally 中仅删除本次新建、已验证名称的独立测试数据库。
